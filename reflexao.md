# Reflexão

O conflito aconteceu porque nós dois alteramos a mesma parte do arquivo ao mesmo tempo.

Decidimos manter a versão que fazia mais sentido para o projeto, juntando as alterações importantes de cada versão.

Em um projeto real, usaríamos branches diferentes para cada tarefa, faríamos commits frequentes e usaríamos Pull Requests para revisar as alterações antes de juntá-las. Isso ajudaria a evitar conflitos.
